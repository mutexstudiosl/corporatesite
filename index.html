Products

Our products

Each product handles a task that Azure or Kubernetes doesn't do out of the box, such as resizing an Azure SQL database on a schedule.

Azure Autoscaler

Scales Azure SQL databases and elastic pools, MySQL, PostgreSQL, Azure file shares, AKS node pools, Azure DevOps, and Fabric capacity from real-time metrics. Use it for resources that Azure doesn't autoscale, or where the built-in autoscaling fails in edge cases, instead of provisioning for peak load all the time.

Available on Microsoft Azure Marketplace
Learn more

Storage Observer

Shows which folders use your storage across local disks, NFS and SMB shares, SharePoint, S3, and Azure. It runs on your own infrastructure and is designed for sources with billions of files.

Learn more

Traefork

A soft-fork of Traefik, kept in sync with upstream, with extra plugins compiled into the binary.
