Traefork

A soft-fork of Traefik, kept in sync with upstream. It precompiles additional plugins into Traefik itself.

Built on Traefik (MIT). Not affiliated with or endorsed by Traefik Labs.

Request Access

The fork

Plugins compiled into Traefik.

Traefik loads community middleware with Yaegi, a Go interpreter. Those middlewares run on every request, so the interpreter sits on the hot path: more memory, more CPU, and profiles that do not show the plugin code.

Traefork keeps the upstream tree in sync and compiles the extra plugins into the binary. The plugin source stays the same. Upstream declined shipping that workflow.

Compiled into the binary

ModSecurity, Geoblock, RealIP, CrowdSec, and Sablier are part of the Traefik build. Yaegi does not run them. A Yaegi plugin can still be loaded when it is not in this set.

Kept in sync with upstream

Each release tracks an upstream Traefik version and pins the plugins compiled into it. The fork carries the compile-in patch.

Tested as a set

The image is exercised with the compiled middlewares before it is published, including a comparison against the same stacks running under Yaegi.

Instead of Front Door

The request is the advantage.

You switch because Traefork handles the request: routing, certificates, and a security stack compiled into the ingress. In Europe, under 10 TB, a gigabyte from Front Door’s edge is $0.083 and a gigabyte from a virtual machine on routing preference Internet is $0.08.

Routing

A Traefik router matches host, path, headers, method, and query, then sends the request to a weighted set of services, a mirror, or a TCP service. Front Door matches host and path. Its rules engine rewrites and redirects, and an origin group can carry a weight.

Certificates

ACME runs on the ingress. The certificate is issued for that route, from an account you control, including a DNS-01 wildcard. Front Door’s managed certificate is free, and it belongs to the Front Door profile.

Security

Rate limit, ModSecurity, and CrowdSec run in that order inside the Traefork process. Each route can carry its own chain. Front Door Premium applies its managed WAF and bot rules at the edge. It does not run ModSecurity or a CrowdSec bouncer.

A quarter of the Front Door bill.

Five million requests a day, about 4 KB on the way back. That is 600 GB out. Front Door Premium is $607.80. Traefork is $143.58. Out to clients is $49.80 from the edge and $40 from the node.
